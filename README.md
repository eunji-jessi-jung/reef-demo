# reef-demo

The demo site for [reef](https://github.com/eunji-jessi-jung/reef) — a walk through
what it found in the [sellflow](https://github.com/eunji-jessi-jung/sellflow) fixture,
and a chat you can ask.

Static pages on GitHub Pages, plus one serverless function that proxies the chat so the
API key never reaches the browser.

## Nothing here is typed by hand

Every number and quotation on the site is extracted from the three published
repositories. Re-run the extractors after they change and the site follows:

```bash
python3 tools/build-evidence.py   # → data/evidence.json  (figures, quotations, the grep)
python3 tools/build-digest.py     # → data/digest.json    (the reef, compressed for the chat)
```

`build-evidence.py` runs the grep for real and sums the CSV for real. If a claim on this
site is wrong, either a repository changed or the extractor is wrong — the site cannot
drift on its own. That is the same discipline the product argues for, applied here.

## The chat

Two layers, so it cannot arrive at a broken state:

- **Prepared questions** (`data/qa.json`) — generated by an agent that could read only
  the reef's artifacts. No network, no cost, always works.
- **Free-form questions** — `api/chat.js`, a Vercel function. If it is absent, over
  budget or unreachable, the input box disappears and the prepared questions remain.

The browser sends a question and nothing else. Model, system prompt, token budget and
context are all fixed server-side, so the abuse surface is "ask about sellflow", not
"free LLM". Limits live at the top of `api/chat.js`.

### Deploying the proxy

```bash
vercel deploy --prod
```

Then set these in the Vercel project's environment variables:

| Variable | Notes |
|---|---|
| `ANTHROPIC_API_KEY` | Required. Set by a human in the dashboard; never committed. |
| `REEF_MODEL` | Default `claude-sonnet-5`. |
| `REEF_REQUEST_BUDGET` | Requests before the site falls back to prepared answers. |
| `REEF_ALLOWED_ORIGINS` | Comma-separated. Defaults to the Pages origin and localhost. |

Finally set `window.REEF_API` in `index.html` to the deployed function URL. Leaving it
empty ships the prepared-answers-only build, which is a complete demo on its own.
